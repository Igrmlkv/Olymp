# Архитектура

## Общая картина

```
                    ┌──────────────────────────────┐
  ребёнок ─────────▶│  PWA (Cloudflare Pages)      │
                    │  React + Vite                │
                    │  service worker + IndexedDB  │
                    └───────────┬──────────────────┘
                                │ /api/*
                    ┌───────────▼──────────────────┐
                    │  Worker-прокси               │
                    │  ключ Anthropic, логирование │
                    └──┬────────┬──────────┬───────┘
                       │        │          │
              ┌────────▼──┐ ┌───▼────┐ ┌───▼──────────────┐
              │ R2 (eu)   │ │ D1 (eu)│ │ Analytics Engine │
              │ пакеты    │ │ аудит  │ │ телеметрия       │
              └───────────┘ └────────┘ └──────────────────┘

  разработчик ──▶ pipeline (generate → verify → publish) ──▶ R2
```

## Почему прокси вообще нужен

Anthropic API из Нидерландов доступен штатно — прокси решает ровно две задачи:
ключ не должен попадать на устройство ребёнка, и расход токенов нужно логировать
в одном месте для сверки с Admin API. Никакой другой логики в нём быть не должно.

## Офлайн-модель

Пакеты задач версионируются и неизменяемы: версия `1.0.0` навсегда остаётся тем же
содержимым. Поэтому service worker кэширует их `CacheFirst` с годовым TTL, а
указатель `latest.json` — с пятиминутным. После первой загрузки приложение работает
полностью без сети: проверка ответов, подсказки из пакета, разборы и режим олимпиады
не требуют сервера. Онлайн нужен только для загрузки нового пакета и для
живых подсказок Haiku (опционально).

Целостность пакета проверяется на клиенте по SHA-256 от канонического JSON списка
задач. Подпись считается одинаково в `pipeline/src/checksum.ts` и
`apps/pwa/src/lib/content.ts`.

## Данные ребёнка

Прогресс, стрики, выбранный класс и очередь телеметрии живут в IndexedDB через Dexie
(`apps/pwa/src/lib/db.ts`). Сервер о них не знает. Это архитектурное решение, а не
деталь реализации: оно убирает согласие родителя по ст. 8 GDPR с критического пути
и снимает необходимость полного DPIA. Родительский экран даёт кнопку полного
удаления данных с устройства.

## Три контура аудита

| Контур | Где | Что |
|---|---|---|
| Провенанс конвейера | D1: `prompt_versions`, `task_provenance`, `verification_verdicts`, `package_versions` | откуда взялась каждая задача и кто её проверил |
| Лог прокси | D1: `proxy_requests` | токены, стоимость, задержки, ошибки; сверка с Admin API |
| Телеметрия | Analytics Engine + D1 `telemetry_daily` | обезличенная решаемость задач |

Сырые события телеметрии не попадают в D1 — только суточные агрегаты без
`installation_id`, которые уже полностью вне сферы GDPR.

## Конвейер контента

1. **Few-shot** — архивные задания ВсОШ из `content/archive/` как якорь сложности.
2. **Генерация** — Claude Opus 5 с extended thinking. Batch API даёт −50 %,
   prompt caching — до −90 % на повторный вход.
3. **Верификация** — независимый прогон-решатель того же Opus 5, три попытки,
   self-consistency. Задача проходит только при единогласии И признании формулировки
   однозначной. Раскол отдаётся Claude Fable 5.1 как арбитру.
4. **Публикация** — только `pass`, с подсчётом checksum и записью в `package_versions`.

Осознанное решение: проверяющая модель не слабее генерирующей. Дешёвый верификатор
воспроизвёл бы ошибки генератора вместо того, чтобы их ловить.

## Соответствие моделей ролям

| Роль | Модель | Почему |
|---|---|---|
| Генерация | `claude-opus-5` | сложность уровня ВсОШ требует сильной модели |
| Верификация | `claude-opus-5` | см. выше |
| Арбитраж спорного и тонкая лингвистика | `claude-fable-5-1` | язык и неоднозначность |
| Подсказки, озвучка, перефраз | `claude-haiku-4-5-20251001` | реальное время и объём |

## Что ещё не реализовано

- Панели админки читают данные — нужны read-эндпоинты на Worker.
- Регистрация service worker в UI (плагин настроен, `registerType: 'prompt'`,
  UI обновления нет).
- Иконки PWA (`apps/pwa/public/icons/`).
- Босс-задачи из архива и «похожая задача после ошибки».
- Значки и карта миров сверх текущего списка тем.
