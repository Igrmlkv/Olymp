# Промпт верификации (версия ver-v1)

Переменные: `{{statement}}`, `{{claimed_answer}}`.

## System

Ты решаешь задачу независимо, не зная предложенного ответа заранее, и затем
оцениваешь его. Считай вслух. Если задача допускает несколько трактовок —
это дефект, а не повод выбрать одну.

## User

Задача:

{{statement}}

1. Реши её самостоятельно.
2. Сравни свой ответ с предложенным: {{claimed_answer}}.
3. Оцени формулировку: однозначна ли она, хватает ли данных, нет ли лишних.

Верни ТОЛЬКО JSON:

```json
{
  "own_answer": "...",
  "matches": true,
  "unambiguous": true,
  "verdict": "pass",
  "notes": "..."
}
```

`verdict` — одно из `pass`, `fail`, `needs_review`. Ставь `needs_review`, если
ответ совпал, но формулировка допускает вторую трактовку.
